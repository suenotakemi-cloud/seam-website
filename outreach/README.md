## 送信の実行手順（誰が・いつ・何を）

順番は「締切確認 → ディーラー先行打診 → プレス → 業界誌 → ディーラー本送信」。図は `images/04_timeline.png`。

| 順 | いつ | 誰が | 何を |
|---|---|---|---|
| 1 | 最初の1日 | 田中 | 狙う業界誌の編集部に電話し、特集号の原稿締切と校了日を確認。`00_facts.md` に記入。**校了済みなら逆算表を組み直す** |
| 2 | 同じ週 | 田中 | 〔要記入〕を埋める：リザーブの提供時期・価格（未定なら「未定」と決める）、数値の時点、連携ディーラー社名の公開可否 |
| 3 | 2〜3日 | 担当者〔要記入〕 | `04_dealer_contacts.csv` のメール7社・フォーム24社の問い合わせページを実際に開き、メールアドレスとフォームURLを確定。確認日を備考に書く |
| 4 | 1週間 | 田中 | 優先度1の18社に先行打診（A-1／B-1／D-1）。反応を「返信」列に記録。社名を出せるディーラーが出れば `01` の本文に反映 |
| 5 | 先行打診の翌週 | 田中 | リリース最終稿・図版を確定し、`02` の取材依頼を媒体別に送付（編集部宛と広告部宛を混ぜない） |
| 6 | 校了の1〜2週前 | 田中 | PR TIMES 配信（企業ID 174537）。同日に Web 媒体へ送付。リリース本文と図版を salon.town の1ページに置く |
| 7 | 配信翌日から | 担当者 | 優先度2〜3にセグメント別に送信（1日20社まで）。フォームは各3のパターン、電話推奨の社は電話→要点をメール |
| 8 | 各送信の7日後 | 担当者 | 未返信にフォロー（各2のパターン）。それでも無反応なら電話 |
| 9 | 誌面掲載後 | 田中 | 「掲載誌をご覧ください」の再送で面談化。KPI を `01` の表で判定 |

## 送信前チェックリスト

### 文面
- [ ] 〔要記入〕〔要確認〕が本文に残っていない
- [ ] 数値は「累計会員6万人」「最高月商7,000万円」のみ。時点を添えた
- [ ] 「業界初」「唯一」「二重予約ゼロ」「完全に防ぐ」を使っていない
- [ ] 他社の実名を出した優劣比較がない
- [ ] hanico／SEAM の実績をサロンタウンの実績として書いていない
- [ ] リンクは1通に1本。添付は付けない（取材依頼は3ファイル以内）

### 特定電子メール法
- [ ] 送信者の名称（株式会社サロンタウン）、住所、受信拒否の通知先が本文末尾にある
- [ ] 送信先は公開されている法人の連絡先である（個人名アドレスへ無断で送らない）
- [ ] 「受信拒否」の申し出があった社は一覧に記録し、二度と送らない

### 宛先
- [ ] 送信先の会社が現存している（登記閉鎖・社名変更を確認した）
- [ ] 同一グループには本社1通のみ
- [ ] メールアドレスは公式サイトの問い合わせページで実際に見た
- [ ] フォームの文字数制限を確認し、150字版が収まる

### 運用
- [ ] 1日の送信は20社まで
- [ ] 送信日・送信済・返信の3列を当日中に埋める
- [ ] 返信があった社は一括送信の対象から外した
- [ ] 業界誌の取材依頼と広告部の出稿相談を、同じメールにしていない

## 想定される最大のリスク（3点）

1. **連絡先の未確認**：一覧は公式サイトを直接開いて作ったものではない。メール7社に未確認のまま送ると、誤送信と信用低下につながる。手順3を飛ばさない
2. **記事が先行して、提供開始日を答えられない**：リザーブの提供時期・価格が未定のまま記事が出ると、問い合わせに「未定」としか答えられず期待だけが膨らむ。決まるまではリリースの主語を「ディーラー連携の進捗」に置く
3. **主語の混同**：hanico（SEAM）とサロンタウンは別法人。SEAM の店舗数やブランド数をサロンタウンの実績のように書くと、記者の確認で崩れる。会社概要と代表コメントの主語を毎回確認する

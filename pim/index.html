商品登録 ログイン

ディーラーの ID とパスワードでログインします（スタッフは同じ ID を使います）。

複数人で同時に登録するので、誰が入れたかを担当者名で残します。担当者一覧が登録されているディーラーでは、ログイン後に名前を選びます。

担当者を選んでください

あなたの名前をタップしてください。写真や登録に「誰が入れたか」として残ります。

設定

パスワードを変更する（スタッフが辞めたときなど）

変更すると、ほかの端末はすべてログアウトされ、新しいパスワードでの再ログインが必要になります。

データを出力する（CSV をこの端末に保存）

PC の取り込み画面と同じものを、スマホからも落とせます。iPhone は「ファイル」に保存、または共有から送れます。

保存先の設定がまだです

Cloudflare で D1（seam-db）と R2（PRODUCT_IMAGES）を繋ぐと使えるようになります。手順は db/SETUP_PIM.md。

    画像をまとめて登録（ファイル名にJANが入っているもの）

    メーカーから届いた画像フォルダをそのまま放り込めます。ファイル名から JAN と何枚目かを読み取ります。
    例: 4901275230122.jpg（1枚目） / 4901275230122_2.png / 4901275230122-3.jpeg / 4901275230122 (4).heic。 形式は何でも構いません（jpg / png / gif / bmp / webp / avif / heic※）。保存されるのはすべて webp です。
    ※ heic は Safari / iPhone から、または対応ブラウザでのみ読めます。

    画像ファイルをここにドロップ、または

    統一フォーマットで出力

    入口が CSV でも Excel でもスマホ登録でも、出口はこの1つの形です。列: JAN・商品名・価格(税抜)・価格(税込)・税区分・税率・内容量・単位・内容量表記・上代・仕入価格・メーカー・ブランド・カテゴリ・商品説明・元商品コード・画像1〜5(URL)・画像枚数・更新日時

    「取り込んだ CSV の形」は、最後に取り込んだファイルの列（例: 菊池 CSV の 商品コード, EC表示名, JAN … 22列）をそのまま出し、右端に 画像1〜5 と 画像枚数 を足します。EC 側は 商品コード（商品ID） で突き合わせてください。

    画像は URL で載ります（https://seam.site/pim-img/products/JAN/枚目.webp）。EC 側はこの URL をそのまま読み込めます。

    写真をまとめてダウンロード（zip）

    登録済みの写真（webp）をファイルにして落とします。ファイル名は JAN か 商品ID（商品コード） のどちらでも作れます。カタログ・営業資料・EC への手動登録に。zip の中に list.csv（ファイル名・商品ID・JAN・商品名・枚目）も入ります。

    上の「メーカーで絞る」がそのまま効きます。Chrome / Edge は保存先を選んで 1 つの zip に直接書き出します（何万枚でも可）。それ以外のブラウザは約 300MB ごとに分けてダウンロードします。

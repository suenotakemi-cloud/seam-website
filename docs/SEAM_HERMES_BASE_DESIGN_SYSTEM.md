# SEAM Hermes-base Design System

最終更新: 2026-08-31

基準実装: `index.html` / `css/home-hybrid-finished.css` / `js/home-hybrid-finished.js`

基準コミット: `0bc9d9f9`
目的: 今後更新するSEAM全ページの視覚・操作・多言語UIを、現在の本番トップと同じ品質へ揃える。

## 1. ブランド方針

- ベースとなる思想はHermèsのモバイルサイト。静けさ、余白、上質な写真、大きく短い見出し、明快な導線を優先する。
- Hermèsの複製ではなく、SEAMの美容・ヘアケア体験へ翻訳する。
- 冷たいテック感、病院のような白さ、安価なコスメEC感は避ける。
- 「高級品だが、女性が楽しく見られる」「華やかだが騒がしくない」を両立する。
- 角丸カードを多用しない。写真は基本的に直角で扱い、必要な箇所だけピル型を使う。
- 1画面1メッセージ。見出し、短い説明、明確なCTAの順で読ませる。

## 5. 写真・動画・オーバーレイ

- 写真は美容と商品が主役。AI感の強いボトル、存在しないラベル、過剰な光沢を避ける。
- 商品画像は本物の正規取扱ブランドを基本とする。
- Hero動画は `object-fit: cover`、PCは `object-position: center 42%`。
- Heroの文字保護: 上35%は透明、58%から暗くし、下部は `rgba(8,4,3,.93)` 相当。
- 写真カードの文字保護: 下から `#140907` 約87% → 68%で透明。
- オンラインショップ: 左を濃く、右67–74%で透明になる横グラデーション。
- 写真上の文字は白、必要時のみ `text-shadow: 0 1–2px 8–12px #000`。
- 髪格診断動画の影: `0 17px 35px rgba(71,45,32,.24)`。
- Heroのみ先読み。下層動画は `preload="none"` とIntersectionObserverで遅延再生。
- 画像はWebP/AVIF、下層は `loading="lazy"` と `decoding="async"`。

## 6. コンポーネント規約

### ヘッダー

- 左: 3本線メニュー。線幅20px、最後のみ13px、線高1px。
- 中央: SEAMロゴ。スマホ21px、PC26px。
- 右: 地球SVG + `JP/EN/CN/TW/KR`。検索アイコンには戻さない。
- 言語ボタンはアイコン18px、ラベル9px、gap 4px。

### CTA

- 原則テキストリンク + 矢印 `→`。
- 下線オフセット5px。
- タッチ領域は最低44px。
- 強いCTAのみ濃茶背景 `#211817` と白文字。

### カード

- 画像全面 + 下部グラデーション + 左下コピー。
- カード間隔はスマホ8px、PC12px。
- 商品検索 → 店舗 → ヘアサロン → スパサロンの順を維持。
- 髪格診断は4カードの上に横長で置く。

### 数字・信頼証明

- 背景 `#211817`、白文字。
- スマホ2列、PC4列。
- 数字はスマホ25px、PC38px。
- `197 BRANDS / 50,000+ MEMBERS / 100% AUTHORISED / 7 LOCATIONS` を基準とする。

## 7. 動きと操作

- 装飾だけのアニメーションは加えない。
- 横スライダーはネイティブスクロール + scroll-snap。
- 押下時は `opacity: .72`。
- キーボードフォーカスは `3px solid #a96844`、offset 3px。
- `prefers-reduced-motion: reduce` では動画を非表示にする。
- すべてのボタン・リンクに `touch-action: manipulation`。
- 横はみ出しは常に0pxであること。

## 8. 多言語

- 対応: 日本語、英語、簡体中国語、繁体中国語、韓国語。
- 表示ラベル: `JP / EN / CN / TW / KR`。
- 選択は `localStorage.seamLang` に保存し、他ページへ引き継ぐ。
- 翻訳後も見出しを2–3行以内に保つ。切れ・省略・横スクロールは禁止。
- ブランド名・スタッフ名・固有名は原則として翻訳しない。
- `html lang` を `ja / en / zh-Hans / zh-Hant / ko` に切り替える。

## 9. SEOをデザインから消さない

- H1は1ページ1つ。
- 見える本文として、ページ固有の説明・ブランド・地域・悩み語を自然に掲載する。
- SEO本文も他セクションと同じ文字・色・余白にし、隠しテキストにしない。
- canonical、hreflang、JSON-LD、OG、descriptionを維持する。
- 下層ページ更新時も既存の検索流入語と内部リンクを削除しない。

## 10. 下層ページ更新チェックリスト

1. Heroは写真または動画1点、短い見出し、説明、主CTAで構成したか。
2. 色はこの暖色パレット内に収まっているか。
3. H1/H2にサンセリフ + oblique 4degを適用したか。
4. スマホ30px、PC44–52pxの見出し基準を守ったか。
5. 余白を削りすぎず、1画面1メッセージになっているか。
6. 写真上の文字がすべて読めるか。
7. タッチ領域44px、focus-visible、aria-labelがあるか。
8. 日本語・英語・中国語2種・韓国語で文字切れがないか。
9. 375pxと1440pxで横はみ出しが0か。
10. 既存SEO本文、構造化データ、内部リンクを保持したか。
